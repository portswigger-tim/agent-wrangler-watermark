## Findings and resolutions

- 2026-11-10: Reviewed the initial CI and release workflows. PR jobs use a read-only token, SHA-pinned actions, no persisted checkout credentials, and no execution of pull-request metadata as shell input. Release writes are confined to the release job on main. No unresolved findings in that workflow review.
- 2026-11-10: Independent bootstrap review found that the staged gitleaks hook scans no committed content on a clean CI checkout. Added a second full-history scan and full checkout history; retained the staged scan for local work. Also added PR title validation, narrowed lockfile exclusions, and kept main CI runs from cancelling each other.
- 2026-11-10: Reviewed the resource tools, persistence, sampling and browser mutations. No arbitrary command execution is exposed. Every agent mutation validates an existing caller and limits access to its own reservations; remote runtimes cannot request host budgets. Labels render as text. Read failures and corrupt state block new grants. Grants persist until explicit release. Initial schema dependency had a high-severity advisory; replaced with patched Zod 4.6.7 and verified host SDK compatibility. No unresolved high-severity findings.
- 2026-11-10: CI exposed a missing network rule for dependency auditing. Permit POST only to npm's bulk-advisory and quick-audit query endpoints, which receive the public dependency list. Registry package writes remain denied; the runner stays in enforce mode.
- 2026-11-10: Independent feature review identified abandoned grants before work starts. Added five-minute offers and an explicit durable claim before execution. Only claimed grants can remain indefinitely; unclaimed offers expire. Sweeps cancel unstarted work for missing/archived owners and reject budgets made impossible by changed settings. Notifications drain separately with timeouts, bounded retries and dead-owner removal; they cannot block admission. Dashboard focus no longer freezes telemetry. Title edits trigger CI and manual releases are restricted to main. Corrected annotated hook tag pins to their underlying commit SHAs without changing hook versions.
- 2026-11-10: Follow-up review verified with Wrangler's real dependency installer in a clean directory, without development dependencies. Verified synchronous session-map loading in the host constructor before extension activation, and sweep startup after initialization. Restricted the declared API range to the tested host API 1.57.x and later compatible 1.x versions. Kept conservative claim accounting and documented/tested that simultaneous offers can pause as measured usage rises. Timed-out mail is now treated as possibly sent and discarded instead of retried; explicit failures still have bounded retries. Status focus survives subsequent dashboard updates.
- 2026-11-10: Added same-user native process sampling for card CPU/RSS. The macOS ps snapshot transiently includes argv/environment; Linux reads bounded process environments. These can contain secrets, so only numeric aggregates and the AW_SESSION_ID identity survive parsing; raw data is never cached, persisted, logged or returned. Subprocess errors are replaced with a fixed message. Process access is read-only, bounded and independent of admission. Tests cover secret stripping, nested ownership, PID reuse, unavailable readings and caller-narrowed measurements. The board operator can disable collection. Docker/container memory is not attributed.
- 2026-11-10: Independent card-display review improved Linux CPU precision with kernel ticks and per-process counter timestamps. Session measurements now have an independent sweep and an abortable five-second deadline; late results cannot replace fresh readings. macOS snapshots stream line by line with fixed size/deadline errors. Buffers expose only bytes actually read. Added large-stream, timeout, cadence, subsecond-counter and keyboard-focus regression tests. Documented the flattened macOS tag ambiguity; it does not affect admission or authorization.

## Living threat model

This is a public extension repository. Untrusted contributions must pass the same local and CI verification gate before merging. Dependency updates and action updates require review. Repository protection settings prevent direct default-branch writes and mutable version tags.

The extension runs trusted code on the Wrangler host. Existing local MCP caller identities and process environment tags are advisory; they are not authentication. The trusted board operator can release stranded reservations and view measured local process aggregates. Resource estimates, cooperative agent behaviour and unrelated host processes limit the admission guarantee. No remote endpoint, executable command tool, telemetry export, or new credential is added. Reservation state remains in the local Wrangler data directory with private permissions; measured process aggregates remain in memory. Only the native host is budgeted; container quotas and remote resources are unsupported.

Dependency tooling note: ESLint 9.39.5 is pinned while the current ESLint 10 dependency tree reports a moderate minimatch advisory. The selected development tree and the sole runtime dependency currently audit clean; Dependabot monitors updates. Revisit the supported lint version once its dependency tree is patched.
